### FU-003 — Enable `VAULT_REQUIRED=true` for production deployments

**Opened:** 2026-05-22
**References:** [`docker-compose.prod.yml`](./docker-compose.prod.yml),
[`vault_env_loader.py`](./vault_env_loader.py)

`VAULT_REQUIRED` is wired through `vault_env_loader.py` (raises
`RuntimeError` on missing creds, auth failure, empty path, or read
failure after 3 retries) but is currently opt-in. Operations team must
enable it explicitly on production hosts to fail-fast on Vault
misconfiguration instead of silently degrading.

**Exit condition:** `VAULT_REQUIRED=true` set in the production
environment file used by `docker-compose.prod.yml`, verified by a deploy
smoke test that fails when Vault is unreachable.
